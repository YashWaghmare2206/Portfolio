# Yash Waghmare — AI/ML Portfolio

A simple static portfolio website built with HTML, CSS and JavaScript for a Software Engineering laboratory experiment demonstrating Git version control, GitHub repository management and GitHub Pages deployment.

## Project Structure

```text
portfolio-experiment/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── Profile Photo.jpg
│   ├── Coursera Certificate AI.png
│   └── Yash Waghmare Coursera Certificate AI.pdf
└── README.md
```

## Run Locally

Open `index.html` in a browser.

For development, a simple local server can also be used, for example:

```bash
python -m http.server
```

## Deployment

The project can be published using GitHub Pages from the repository's `main` branch.
